# Платформа корпоративных карт

Внутренняя платформа выпуска виртуальных карт.

## С чего начать

1. `SETUP.md` — что установить и как запустить. Делать по порядку.
2. `PROMPTS.md` — готовые команды для Claude Code, по одной на этап.
3. `CLAUDE.md` — правила проекта, Claude Code читает их сам.

## Порядок

1. **Прототип** (`docs/prototype.md`) — кликабельные интерфейсы на
   фикстурах, показ руководству, сбор правок.
2. **Разработка** (`docs/roadmap.md`) — по этапам, после утверждения.

Этап 1 разработки — расчёт денег — нельзя сокращать: на нём держится
всё остальное. В прототипе денежной логики нет вообще.
