# Референсы

Claude Code читает эти картинки напрямую. Перед работой над визуалом
посмотреть их и прочитать `docs/design-direction.md` — там разбор,
что из них берём, а что нет.

```
brand-board.png       фирменный стиль: логотип, цвета, градиенты, зерно
admin/                референсы админки
app/                  референсы приложения пользователя
```

## Важное

**Цвета берём свои**, из `docs/brand.md`. В референсах синий — это не
наша палитра. Берём композицию, плотность и приёмы.

**Не всё из референсов применимо.** Что именно не берём и почему —
в `docs/design-direction.md`. Там же структура наших экранов.
